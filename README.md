# farid-zahran

Personal portfolio website for **Farid Zahran** — Software Engineer & AI Engineer.

Dark, cinematic, single-page portfolio built with performance and SEO as first-class priorities.

## Tech Stack

| Layer      | Technology                          |
|------------|-------------------------------------|
| Framework  | Next.js (App Router, Static Export) |
| Language   | TypeScript                          |
| Styling    | Tailwind CSS v4                     |
| Animation  | GSAP + Framer Motion                |
| Deployment | Vercel                              |

## Project Structure

```
├── DESIGN.md              # Halide design system documentation
├── design-tokens.json     # Design tokens (colors, typography, spacing, etc.)
├── SPEC.md                # Product specification / PRD
└── src/                   # Application source (Next.js App Router)
```

## Design System

This project uses the **Halide** design system — a dark cinematic aesthetic with monochrome palette and a single `#9ba480` green accent. See [DESIGN.md](DESIGN.md) for full documentation and [design-tokens.json](design-tokens.json) for token values.

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production (static export)
npm run build
```
